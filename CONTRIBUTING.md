# Работа над CloudPilot AI

Текущий этап — 1. Не добавляйте реализации будущих сервисов без перехода к нужному этапу.
Код и технические имена — на английском, документация — на русском.

1. Создайте ветку от `main`; опишите конкретную проблему и границы изменения.
2. Обновите документацию и ADR, если меняется архитектурное решение.
3. Выполните `make check test` (Python 3.12). Перед коммитом проверьте
   `git diff`, `git diff --cached` и `git diff --cached --check`.
4. Не добавляйте `.env`, токены, kubeconfig, state-файлы и реальные дампы.
   Для примеров используйте пустые значения. При утечке сначала отзовите секрет.
5. В PR укажите выполненные проверки и фактические ограничения. Нельзя писать «CI прошёл»
   до получения успешного результата соответствующего коммита на GitHub.

В текущем CI есть backend/frontend-тесты, PostgreSQL-интеграции и Docker build + smoke.
Тесты в `tests/` проверяют настоящий инструмент контроля репозитория.
Подключение будущих проверок описано в [quality.md](docs/development/quality.md).
