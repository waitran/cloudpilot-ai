# ADR 0001: модульный монолит

Дата: 2026-11-17. Статус: принято для начальной реализации.

## Контекст

Проект разрабатывает один человек с Codex. Система должна разделять расчёты, AI,
эксперименты и исполнительные полномочия, сохраняя простоту локальной разработки.

## Решение

Начать с модульного Python backend и отдельного React frontend. Держать границы доменных
модулей явными, хранить состояние в PostgreSQL. Выносить долгие задачи в отдельный процесс
той же кодовой базы, лабораторию — в изолированное окружение. Не создавать микросервисы заранее.
Safety Controller единолично допускает инфраструктурную запись; AI только предлагает действия.

## Следствия

Проще транзакции, развёртывание, отладка и тестирование. Нужны контроль импортов и прав
процессов: программные границы сами по себе не заменяют изоляцию executor и credentials.
При необходимости отдельный модуль можно выделить в сервис без изменения доменных контрактов.

## Рассмотренные варианты

- Микросервисы с отдельной БД и очередью для каждого модуля — чрезмерная операционная нагрузка.
- Один неструктурированный backend с прямыми вызовами SDK из AI — неприемлемая связность и риск.

Пересмотреть решение при разных требованиях к масштабированию, изоляции или владению модулями.
