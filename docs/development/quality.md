# Проверки качества

Текущий CI выполняет только существующий код: проверку репозитория и её регрессионные тесты.
Зависимостей pip/npm и сборки контейнеров на этапе 0 нет. Неизвестный статус удалённого CI
нельзя считать успешным. Используются GitHub-hosted Ubuntu 24.04, Python из `.python-version`,
Actions закреплены за SHA опубликованных релизов.

## Локально

```bash
make check test
```

`check_repository.py` проверяет обязательные файлы/директории, границу репозитория,
UTF-8/LF/пробелы, синтаксис Python, JSON и TOML, относительные Markdown-ссылки,
закрытие code fences, шаблон окружения и исключения Git. Проверка признаков секретов
выполняется для рабочих файлов и отдельно для staged blobs: очистка рабочей копии
не скрывает секрет, который остался в индексе.

YAML workflow разбирается GitHub при запуске. При подготовке также выполнен локальный разбор
доступным PyYAML; основной checker не требует этого стороннего пакета.
Mermaid проверен по структуре текста; полноценный рендер на GitHub до публикации не подтверждён.

## Подключение при появлении приложения

| Проверка | Когда подключать | Условия |
| --- | --- | --- |
| Ruff check/format | Этап 1 | Добавить закреплённый dev dependency; использовать корневой `ruff.toml` |
| pytest | Этап 1 | Реальный backend; unit и интеграционные тесты с PostgreSQL; пустой набор тестов должен завершаться ошибкой |
| ESLint/Prettier | Этап 1 | Реальный frontend, локальные dev dependencies, lock-файл и scripts; основа Prettier уже в корне |
| TypeScript | Этап 1 | tsconfig и настоящий код; `tsc --noEmit` либо проверка build-конфига |
| Docker build | Этап 1 | Настоящие Dockerfile и Compose; health/readiness и проверка миграций |
| k6/SLO | Этап 6 | Изолированное окружение, реальные результаты baseline и кандидатов |

ESLint и pytest-конфиги не создаются заранее без выбранных версий и реального приложения.
Не нужны `|| true`, фиктивные тесты и успешные заглушки jobs. Новые проверки должны падать
при нарушении проверяемого условия. Скрипты этапа 0 не являются реализацией модулей платформы.
